# 戶型裝修設計

純前端的戶型裝修設計工具：在 2D 平面圖上擺放傢俱、拆改牆體、測量尺寸，一鍵切換到 Three.js 3D 場景，可以鳥瞰，也可以第一人稱漫遊。整個應用就是一個 `index.html`，無需構建，開啟即用。

## 功能

**2D 平面佈置**
- 按原始戶型 1:60 / 1:100 比例顯示，尺寸單位 mm
- 從左側傢俱庫拖入 60 餘種傢俱家電（臥室、客廳、餐廚、衛浴、家電、書房休閒）
- 拖動移動、旋轉（Shift 自由角度）、調整尺寸，貼牆自動吸附
- 測量工具（靠近牆面自動吸附，Shift 鎖定水平 / 垂直）
- 拆改非承重牆，承重牆單獨標示
- 圖層開關：尺寸標註、房間名、傢俱、網格、承重牆

**3D 場景**
- 鳥瞰、斜視、俯視多種視角，點選房間列表可飛到對應房間
- 漫遊模式：桌面端 WASD + 滑鼠，觸屏裝置用虛擬搖桿，可以點門開關
- 全高牆 / 剖切牆切換，日照時間滑塊，夜景燈光
- 精細傢俱模型：櫃門分縫與拉手、軟包床頭、帶環境反射的金屬與陶瓷材質等
- 在 3D 中也能選中、拖動傢俱，與 2D 方案實時同步

**方案與統計**
- 房間面積與套內使用面積自動統計
- 為每個房間更換地面材料（木地板、地磚、大理石、水磨石、地毯等），按面積加 5% 損耗估算造價
- 撤銷 / 重做，方案自動儲存在瀏覽器本地
- 中文 / English 介面切換（頂欄右側按鈕，預設中文，選擇會記住）
- 匯出 PNG 圖片，匯出 / 匯入方案 JSON

## 快速開始

```bash
git clone <倉庫地址>
cd <倉庫目錄>
```

然後直接用瀏覽器開啟 `index.html`。也可以起一個本地靜態伺服器：

```bash
python3 -m http.server 8000
# 訪問 http://localhost:8000
```

> Three.js 透過 jsDelivr CDN 載入，首次開啟 3D 場景需要聯網。

## 快捷鍵

| 按鍵 | 作用 |
| --- | --- |
| `T` | 切換 2D / 3D |
| `V` / `M` / `X` | 選擇 / 測量 / 拆改牆體 |
| `R` / `Shift+R` | 選中傢俱順時針 / 逆時針旋轉 90° |
| `Delete` / `Backspace` | 刪除選中傢俱 |
| `Ctrl/⌘ + D` | 複製選中傢俱 |
| `Ctrl/⌘ + Z`，`Ctrl/⌘ + Shift + Z` | 撤銷，重做 |
| `F` | 適應視窗 |
| `+` / `-` | 放大 / 縮小 |
| `[` / `]` | 展開 / 收起左側傢俱庫、右側面板 |
| `Shift + F` | 全屏 |
| `Esc` | 取消當前操作 |
| 漫遊：`WASD` / 方向鍵，`Shift`，`E` | 移動，快走，開關門 |

## 技術棧

- 原生 HTML / CSS / JavaScript，無框架、無構建步驟
- 2D 平面圖用 SVG 繪製
- 3D 場景用 [Three.js](https://threejs.org/) r160（OrbitControls、PointerLockControls、RoundedBoxGeometry、RoomEnvironment、CSS2DRenderer）
- 資料儲存在 `localStorage`

## 自定義戶型

戶型資料寫在 `index.html` 裡：

- `ROOMS`：房間多邊形、名稱、預設地面材料
- `WALLS` / `WINS`：牆體與窗洞
- `MATS`：地面材料名稱與單價
- `LIB`：傢俱庫（型別、名稱、預設尺寸、顏色）
- `buildFurniture()`：各類傢俱的 3D 模型

改這些資料就能換成自己的戶型。
